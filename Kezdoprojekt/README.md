# Konzolos rajzoló kezdőprojekt

Nyisd meg a Rajzolo.csproj fájlt a Visual Studióban, majd indítsd a Ctrl+F5 billentyűkkel. Parancssorból, a projekt mappájában: dotnet run. A projekthez .NET 8 SDK kell. A hangpróbához használj Windowsos gépet. Az ablak legyen legalább 76 oszlop széles és 23 sor magas.

F1 kiír egy színes jelet. B hangpróbát indít. L beolvassa és megmutatja a mellékelt minta.txt rövid tartalmát. Esc kilép. Ezek a kezdőprojekt próbabillentyűi. A kész program vezérlését a feladatlap szerint alakítsátok ki.

A fájlkezelési példa egy előre ismert, rövid mintával dolgozik. A kész programban a fájl minden sorának méretét még a kirajzolás előtt ellenőrizzétek. A Program.cs kiindulópontként használható vagy átszervezhető.
